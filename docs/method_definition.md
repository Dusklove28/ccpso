# CCPSO 当前研究方法定义

## 1. 研究对象

本项目当前研究的算法是 **Convergence-Controlled PSO（CCPSO）**：

\[
X_{t+1}=\operatorname{clip}\!\left(Q_t+C_tP_t,\,l,\,u\right).
\]

忽略边界投影时，其核心形式为：

\[
X_{t+1}=Q_t+C_tP_t.
\]

其中，\(Q_t\) 是由个体历史最优位置与群体全局最优位置形成的榜样
中心，\(P_t\) 是相对于 \(Q_t\) 的二阶残差（扰动）项。强化学习控制的
对象是残差项 \(P_t\) 的缩放系数 \(C_t\)，不是直接生成粒子位置。

对每个粒子、每个坐标，定义

\[
Q_t=
\frac{
c_1r_1Pbest_t+c_2r_2Gbest_t
}{
c_1r_1+c_2r_2
},
\]

\[
\phi_t=c_1r_1+c_2r_2,
\]

以及

\[
P_t=
(1+w-\phi_t)(X_t-Q_t)
-w(X_{t-1}-Q_t).
\]

最终更新为

\[
X_{t+1}
=
\operatorname{clip}
\left(
Q_t+C_tP_t,\,l,\,u
\right).
\]

这里的 \(r_1,r_2\) 是逐粒子、逐坐标采样的随机权重，所有乘法和除法
均按元素进行，\(Gbest_t\) 按粒子维广播。实现中，当
\(c_1r_1+c_2r_2\) 在浮点意义下接近零时，为避免除零，相关坐标的
\(Q_t\) 退化为 \((Pbest_t+Gbest_t)/2\)；正常权重下严格使用上述加权
中心公式。

## 2. 与胡建等论文的关系和边界

本方法参考：胡建、胡旺、殷锋，《粒子群优化算法位置更新方程的统一及
简化》，DOI：`10.1360/N112016-00096`。

当前实现中的 \(Q_t\) 以及 \(Q_t+P_t\) 分解来源于该论文式（17）—
（18）。本项目在式（18）的扰动项 \(P_t\) 前引入可控系数 \(C_t\)，得到

\[
X_{t+1}=Q_t+C_tP_t.
\]

必须明确区分：当前方法**不是**该论文式（21）的高斯采样模型

\[
Q+\mathcal N(0,C|Q-X|).
\]

因此：

- 当前 \(C_t\) 是确定性二阶残差项 \(P_t\) 的缩放系数；
- 当前 \(C_t\) 不是高斯分布的标准差；
- 论文针对式（21）推导的 \(|C|<1\) 收敛结论，不能直接声明为当前
  \(X_{t+1}=Q_t+C_tP_t\) 方法的理论保证。

本项目中的 `linear_c` 仅表示当前方法的人工线性控制基线，即随代数
线性改变残差缩放系数 \(C_t\)。它不是论文式（21）的直接复现，也不应
被称为论文式（21）的高斯 CCPSO 基线。

## 3. 当 \(C_t=1\) 时与经典 PSO-Clerc 的等价性

当 \(C_t=1\) 且忽略边界处理时：

\[
\begin{aligned}
Q_t+P_t
&=Q_t+(1+w-\phi_t)(X_t-Q_t)
-w(X_{t-1}-Q_t)\\
&=(1+w-\phi_t)X_t-wX_{t-1}+\phi_tQ_t\\
&=(1+w-\phi_t)X_t-wX_{t-1}
+c_1r_1Pbest_t+c_2r_2Gbest_t.
\end{aligned}
\]

这与使用相同 \(w,c_1,c_2,r_1,r_2\) 的经典 PSO-Clerc 位置二阶递推
完全一致。这里的等价性针对未发生边界投影的更新；若候选位置越界，
实际位置还会经过 \(\operatorname{clip}\) 处理。

## 4. 收敛控制系数的特殊情况

- \(C_t=1\)：恢复当前参数下的经典 PSO-Clerc 位置二阶递推；
- \(C_t=0\)：新位置直接取 \(Q_t\)；
- \(0<C_t<1\)：缩小相对于 \(Q_t\) 的二阶残差；
- \(C_t>1\)：放大相对于 \(Q_t\) 的二阶残差。

这些描述定义的是 \(C_t\) 对当前更新式的直接作用。它们本身不构成对
任意动态 \(C_t\)、有限边界或移动 \(Pbest/Gbest\) 系统的收敛性证明。
